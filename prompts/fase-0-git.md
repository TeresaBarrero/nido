Hola. Estás en la carpeta del proyecto Nido. Lee primero `CLAUDE.md`.

Quiero subir este kit a mi repositorio vacío de GitHub: https://github.com/TeresaBarrero/nido.git

1. Comprueba si tengo git instalado y configurado (nombre y correo). Si falta algo, dime qué comando ejecutar o hazlo tú tras pedirme permiso.
2. Inicializa el repositorio en esta carpeta, con la rama `main`.
3. Haz un primer commit con todo el kit: "chore: add Nido starter kit (spec, tokens, prototype, photos)".
4. Conecta el remoto `origin` con la dirección de arriba y sube la rama.
5. Si GitHub me pide iniciar sesión, explícame paso a paso cómo hacerlo (por ejemplo con GitHub CLI o con el navegador).

Al terminar, dime cómo comprobar en github.com que los archivos están subidos.
